Test Instructions & Guidelines

Test Title: {Subject Name} - Mock Examination 2026

General Instructions:
  • Duration: You will have 60 minutes to complete the examination.
  • Question Count: The test consists of 50 Multiple Choice Questions (MCQs).
  • Marking Scheme: Each correct answer awards +5.00 marks. A penalty of -1.00 mark is applied for each incorrect response. Unanswered questions receive 0 marks.
  • Navigation: You can move between questions using the Question Palette on the right side of the screen.
  • Review System: You may use the "Mark for Review" button to flag questions you wish to revisit later.
Important Rules:
  1. Fullscreen Mode: You can enter Fullscreen Mode for a more immersive experience using the toggle button in the header. Exiting fullscreen or navigating away will trigger a security warning.
  2. Auto-Submit: The test will automatically submit once the timer reaches 00:00:00. Ensure all your answers are saved before time expires.
  3. Evaluations: Only questions that are "Saved" or "Answered & Marked for Review" will be considered for the final score. Questions marked for review without saving an answer will NOT be evaluated.
  4. No Pausing: Once started, the timer cannot be paused or stopped. Plan your time management accordingly.
  5. Exit Warning: Exiting the test before submission will result in complete loss of progress. There is no option to resume the test.
  6. Single Attempt: Each test configuration can only be attempted once per session. Refreshing or closing the browser will terminate your attempt.
Question Status Guide:
Answered (Green)
Not Answered (Red)
Not Visited (Gray)
Marked for Review (Purple)
Answered & Marked for Review (Green-Purple)
Best Practices:
  • Read each question carefully before selecting your answer
  • Use "Save & Next" to confirm your response before moving forward
  • Utilize the "Mark for Review" feature for questions you're uncertain about
  • Monitor the remaining time regularly using the timer in the header
  • Review all marked questions before final submission
  • Ensure you have a stable internet connection throughout the test
