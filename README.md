# Political-Science-Mock-Test-Portal
A modern Political Science mock test and preparation platform featuring interactive quizzes, performance analytics, leaderboards, answer keys, result dashboards, and student progress tracking.

The platform allows students to select subjects and chapters, attempt timed mock tests, track performance, view detailed answer keys, and analyze their strengths and weaknesses chapter-wise.

## Features

* Subject-wise and chapter-wise mock tests
* Single-select and multi-select chapter modes
* Timed practice sessions with countdown timer
* Reshuffle questions option
* Full CBT-style exam interface
* Question palette with navigation
* Mark for review and save & next functionality
* Instant result dashboard
* Donut chart overview for marks and performance
* Detailed answer key page
* Question-wise breakdown table
* Chapter-wise performance analysis
* Accuracy and time analysis
* Responsive and modern UI
* Glassmorphism-inspired cards and layouts
* Footer with social and contact links

## Pages Included

### Home Page

The landing page allows users to:

* Choose a subject
* Select one or multiple chapters
* Choose test mode
* Enable or disable reshuffling
* Start the test
* View platform features and usage steps

The home page also includes a hero section, key features section, process timeline, and footer. 

### Test Page

The test page provides a complete CBT-style interface with:

* Timer
* Question navigation palette
* Save & Next button
* Previous button
* Mark for Review option
* Clear Response button
* Submit modal
* Exit modal
* Question progress tracking

Students can move between questions easily and track their answered, unanswered, reviewed, and not visited questions. 

### Result Page

The result page includes:

* Marks overview section
* Performance percentage
* Time taken
* Correct, incorrect, and unanswered question counts
* Question-wise breakdown
* Filter system for question status
* Chapter-wise analysis
* Answer key access button

The result dashboard helps students understand their weak areas and improve their preparation. 

### Answer Key Page

The answer key page provides:

* Detailed answers for every question
* Question navigator grid
* Back to result button
* Easy review of correct and incorrect responses

Students can revisit their performance and learn from mistakes after completing the test.

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/political-science-mock-portal.git
```

2. Open the project folder

```bash
cd political-science-mock-portal
```

3. Open the project in your code editor

Example:

```bash
code .
```

4. Run the project using Live Server or any local server extension.

Example:

* Install Live Server extension in VS Code
* Right click on index.html
* Click "Open with Live Server"
